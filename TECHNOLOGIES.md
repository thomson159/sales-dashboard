## Technologies

This project uses the following technologies:

### Frontend

- **React** – a library for building user interfaces in a component-based way.
- **React DOM** – integration of React with the browser DOM.
- **React Router** – manages routing in the application, allowing navigation between pages.
- **Tailwind CSS** – utility-first CSS framework for rapid styling.
- **Sass** – CSS preprocessor enabling variables, nesting, and functions in styles.

### TypeScript & Linting

- **TypeScript** – a superset of JavaScript with types, providing safer code.
- **ESLint** – tool for detecting and fixing issues in JavaScript/TypeScript code.
- **Prettier** – automatic code formatting according to project style.
- **@typescript-eslint** – ESLint integration for TypeScript, enabling linting of TS code.

### Data & Charts

- **@nivo/bar, @nivo/line, @nivo/pie, @nivo/scatterplot** – libraries for creating interactive charts.
- **Recharts** – alternative library for creating charts in React.
- **date-fns** – library for working with dates.
- **zod** – validation of data and schemas in TypeScript.

### Build & Dev Tools

- **Vite** – fast bundler and development server for front-end projects.
- **@vitejs/plugin-react** – Vite plugin for React support.
- **vite-tsconfig-paths** – automatic mapping of paths from tsconfig.json.
- **vite-plugin-compression** – compresses build files for better performance.

### Testing

- **Vitest** – unit testing framework similar to Jest, integrated with Vite.
- **@testing-library/react** – tool for testing React components.
- **@testing-library/jest-dom** – extended matchers for DOM testing.
- **jsdom** – simulates a browser environment in Node for DOM testing.

### Misc / Helpers

- **rc-slider** – slider component for React.
- **isbot** – detects bots in Node.js (useful for SSR).
- **react-datepicker** – date picker component for React.
- **rollup-plugin-visualizer** – visualizes the application bundle.
- **autoprefixer / postcss** – automatically adds CSS prefixes for cross-browser compatibility.
